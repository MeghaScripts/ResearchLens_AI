# 🔬 ResearchLens AI — Research Gap Detection System
### Autonomous Research Gap Detection using Agentic AI & Knowledge Graphs

---

## 🚀 STEP-BY-STEP SETUP GUIDE (Beginner Friendly)

---

### STEP 1 — Get Your FREE Groq API Key (2 minutes)

1. Open your browser and go to: **https://console.groq.com**
2. Click **Sign Up** (it's completely free, no credit card needed)
3. Once logged in, click **"API Keys"** in the left sidebar
4. Click **"Create API Key"**
5. Copy the key — it starts with `gsk_...`
6. Keep it somewhere safe (you'll paste it into the app)

---

### STEP 2 — Install Python (if not already installed)

1. Go to: **https://www.python.org/downloads/**
2. Download **Python 3.10 or higher**
3. During installation, ✅ check **"Add Python to PATH"**
4. Finish installation

To verify, open Command Prompt (Windows) or Terminal (Mac/Linux) and type:
```
python --version
```
You should see something like `Python 3.11.x`

---

### STEP 3 — Open the Project in VS Code

1. Open **Visual Studio Code**
2. Go to **File → Open Folder**
3. Select the `research_gap_detector` folder
4. Open the **Terminal** inside VS Code:
   - Go to menu: **Terminal → New Terminal**

---

### STEP 4 — Install Dependencies

In the VS Code Terminal, type these commands one by one:

```bash
cd research_gap_detector
pip install -r requirements.txt
```

Wait for everything to install (1-2 minutes). You'll see lots of text — that's normal!

---

### STEP 5 — Run the Application

In the same terminal, type:

```bash
cd backend
python app.py
```

You should see:
```
 * Running on http://127.0.0.1:5000
 * Debug mode: on
```

---

### STEP 6 — Open the Dashboard

1. Open your browser (Chrome recommended)
2. Go to: **http://localhost:5000**
3. The ResearchLens AI dashboard will load! 🎉

---

## 🎯 HOW TO USE THE APP

1. **Enter your Groq API Key** in the first field
2. **Type your research topic** (e.g., "Machine Learning for Healthcare")
3. **Upload your paper (PDF)** — optional but gives better results
4. Click **"Analyze Research Gaps"**
5. Wait ~30-60 seconds for the analysis
6. Explore the results across 5 tabs:
   - **Overview** — Scores, summary, coverage analysis
   - **Research Gaps** — Detailed gap cards with suggestions
   - **Knowledge Graph** — Interactive visualization
   - **Papers** — Related papers found from ArXiv
   - **Trends** — Publication charts and emerging trends
7. Click **"Download Report"** to get a professional PDF

## 🛠️ TROUBLESHOOTING

**"Module not found" error?**
→ Run: `pip install -r requirements.txt` again

**"Connection refused" or app won't load?**
→ Make sure `python app.py` is still running in terminal

**API Key error?**
→ Double-check your Groq key starts with `gsk_`

**ArXiv returns no papers?**
→ Check your internet connection; try a broader topic

**PDF not being read?**
→ Make sure it's a text-based PDF, not a scanned image
